### Prettier Configuration

```json
{
  "semi": true,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5",
  "printWidth": 80
}
```

### Package.json Scripts

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "eslint . --ext .ts,.tsx",
    "lint:fix": "eslint . --ext .ts,.tsx --fix",
    "type-check": "tsc --noEmit",
    "prepare": "husky install"
  }
}
```

### VSCode Settings

```json
{
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  },
  "editor.defaultFormatter": "esbenp.prettier-vscode"
}
```

### Testing

#### Testing Standards

- All code must pass ESLint without errors
- Prettier must format code consistently
- Pre-commit hooks must prevent commits with linting errors
- TypeScript compilation must succeed

#### Testing Approach

1. Create intentionally poorly formatted files
2. Run lint and verify errors are caught
3. Run lint:fix and verify auto-correction
4. Attempt commit and verify hook enforcement
5. Run type-check and verify TypeScript validation
