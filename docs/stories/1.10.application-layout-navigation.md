# Story 1.10: Application Layout and Navigation Framework

## Status
Draft

## Story
**As a** user,
**I want** a responsive application layout with intuitive navigation,
**so that** I can easily access different sections of the platform.

6. Create placeholder dashboard page accessible after authentication

### Main Layout Example
```typescript
// components/layout/main-layout.tsx
'use client';

import { useState } from 'react';
import { Header } from './header';
import { Sidebar } from './sidebar';

export function MainLayout({ children }: { children: React.ReactNode }) {
  const [sidebarOpen, setSidebarOpen] = useState(true);

  return (
    <div className="h-screen flex flex-col">
      <Header onMenuClick={() => setSidebarOpen(!sidebarOpen)} />
      <div className="flex flex-1 overflow-hidden">
        <Sidebar isOpen={sidebarOpen} />
        <main className="flex-1 overflow-y-auto p-6 bg-gray-50">
          {children}
        </main>
      </div>
    </div>
  );
}
```

### Navigation Items

### Responsive Breakpoints
- Mobile: < 768px (sidebar as drawer)
- Tablet: 768px - 1024px (collapsible sidebar)
- Desktop: > 1024px (expanded sidebar default)

### ShadCN Components to Use
- Button (navigation items, user dropdown)
- DropdownMenu (user profile menu)
- Sheet (mobile sidebar drawer)
- Separator (visual divisions)
- Avatar (user profile image)

### Testing
#### Testing Standards
- Layout must not break at any viewport size
- Navigation must be keyboard accessible
- Active routes must be visually indicated
- Loading states must prevent layout shift

#### Testing Approach
1. Test all viewport sizes in browser dev tools
2. Test keyboard navigation (Tab, Enter, Escape)
3. Test mobile menu open/close
4. Test sidebar collapse/expand
5. Verify user dropdown shows correct user info
6. Test navigation between pages

#### Responsive Test Checklist
- [ ] 320px: Mobile drawer works, no horizontal scroll
- [ ] 768px: Tablet layout transitions properly
- [ ] 1024px: Desktop sidebar expands
- [ ] 1920px: Content doesn't stretch excessively
- [ ] Touch gestures work on mobile devices
- [ ] Keyboard navigation works throughout
