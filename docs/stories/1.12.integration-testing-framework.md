# Story 1.12: Integration Testing Framework and External Service Mocking

## Status
Draft

## Story
**As a** developer,
**I want** comprehensive testing infrastructure for external service integrations,
**so that** the application can be tested reliably without depending on external service availability.

## Acceptance Criteria
1. Set up MSW (Mock Service Worker) for mocking external API responses during testing
2. Create test fixtures for Claude Code SDK responses with various generation scenarios
3. Implement E2B sandbox service mocking for preview functionality testing
4. Build integration tests that validate external service error handling
5. Create test data sets for different AI generation success and failure cases
6. Set up automated testing that runs against mocked services in CI/CD pipeline
7. Document testing procedures for external service integration validation

### Anthropic Mock Handlers
```typescript
// mocks/handlers/anthropic.ts
import { http, HttpResponse } from 'msw';

export const anthropicHandlers = [
  http.post('https://api.anthropic.com/v1/messages', async ({ request }) => {
    const body = await request.json();

    // Successful response
    if (body.messages[0].content.includes('create a button')) {
      return HttpResponse.json({
        id: 'msg_test123',
        type: 'message',
        role: 'assistant',
        content: [
          {
            type: 'text',
            text: 'export default function Button() { return <button>Click me</button> }',
          },
        ],
        model: 'claude-3-5-sonnet-20241022',
        stop_reason: 'end_turn',
        usage: {
          input_tokens: 20,
          output_tokens: 50,
        },
      });
    }

    // Rate limit error
    if (body.messages[0].content.includes('rate_limit_test')) {
      return HttpResponse.json(
        { error: { type: 'rate_limit_error', message: 'Rate limit exceeded' } },
        { status: 429 }
      );
    }

    // Default success
    return HttpResponse.json({
      id: 'msg_default',
      type: 'message',
      role: 'assistant',
      content: [{ type: 'text', text: '// Generated code' }],
      model: 'claude-3-5-sonnet-20241022',
      stop_reason: 'end_turn',
      usage: { input_tokens: 10, output_tokens: 20 },
    });
  }),
];
```

### E2B Mock Handlers
```typescript
// mocks/handlers/e2b.ts
import { http, HttpResponse } from 'msw';

export const e2bHandlers = [
  // Sandbox creation
  http.post('https://api.e2b.dev/sandboxes', () => {
    return HttpResponse.json({
      sandboxId: 'sandbox_test123',
      status: 'running',
    });
  }),

  // Sandbox execution
  http.post('https://api.e2b.dev/sandboxes/:id/execute', () => {
    return HttpResponse.json({
      stdout: 'Application running on port 3000',
      stderr: '',
      exitCode: 0,
    });
  }),
];
```

### Example Integration Test
```typescript
// tests/integration/ai-generation.test.ts
import { describe, it, expect } from 'vitest';
import { generateWithRetry } from '@/lib/services/anthropic-wrapper';

describe('AI Code Generation', () => {
  it('successfully generates code', async () => {
    const result = await generateWithRetry('create a button');

    expect(result).toContain('Button');
    expect(result).toContain('button');
  });

  it('handles rate limit errors with retry', async () => {
    // Test retry logic
    await expect(
      generateWithRetry('rate_limit_test')
    ).rejects.toThrow('Rate limit exceeded');
  });
});
```

### Testing
#### Testing Standards
- All external service interactions must have mocked tests
- Tests must not depend on external service availability
- Mocks must accurately represent real API responses
- Test coverage should exceed 80% for critical paths

#### Testing Framework
- Vitest for test runner
- MSW for API mocking
- Testing Library for component tests

#### Testing Approach
1. Start MSW server before tests
2. Run integration tests with mocked APIs
3. Verify error handling works correctly
4. Test retry logic with controlled failures
5. Verify test coverage meets thresholds
