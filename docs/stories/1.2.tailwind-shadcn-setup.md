# Story 1.2: Tailwind CSS and ShadCN UI Setup

## Status
Draft

## Story
**As a** developer,
**I want** Tailwind CSS with ShadCN components configured,
**so that** consistent, accessible UI components are available throughout the application.

## Acceptance Criteria
1. Install and configure Tailwind CSS with Next.js App Router support
2. Set up `tailwind.config.js` with custom theme tokens and ShadCN compatibility
3. Initialize ShadCN with `npx shadcn-ui@latest init` and configure components.json
4. Install essential ShadCN components: Button, Input, Card, Dialog, Toast
5. Create `lib/utils.ts` with `cn` utility function for conditional classes
6. Set up CSS variables for theme colors in `globals.css`
7. Verify responsive design tokens work across breakpoints (sm, md, lg, xl, 2xl)

## Dev Notes

### Dependencies
- **Depends on:** Story 1.1 (Next.js setup with globals.css)
- **Required for:** Story 1.10 (Application layout components)

### Technical Requirements
- Tailwind CSS v3+
- ShadCN UI components from official registry
- Support for dark mode theming
- Responsive design from 320px to 2560px

### Component Installation
Install components using ShadCN CLI:
```bash
npx shadcn-ui@latest add button
npx shadcn-ui@latest add input
npx shadcn-ui@latest add card
npx shadcn-ui@latest add dialog
npx shadcn-ui@latest add toast
```

### Utility Function Pattern
The `cn()` utility should merge Tailwind classes using clsx and tailwind-merge:
```typescript
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

### Testing
#### Testing Standards
- Create test components using all installed ShadCN components
- Verify components render correctly in both light and dark modes
- Test responsive behavior at all defined breakpoints
- Ensure no CSS conflicts or console warnings

#### Testing Requirements
- All ShadCN components must render without errors
- Tailwind classes must apply correctly
- cn() utility must properly merge conflicting classes
- Theme switching must work without visual glitches
