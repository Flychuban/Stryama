### TypeScript Type Definitions
[Source: architecture.md - Coding Standards]

**Use enums for application types (3+ values):**
```typescript
enum ApplicationType {
  LANDING_PAGE = 'landing_page',
  DASHBOARD = 'dashboard',
  CRUD_APP = 'crud_app',
  CUSTOM = 'custom'
}

enum PromptRole {
  SYSTEM = 'system',
  USER = 'user',
  ASSISTANT = 'assistant'
}

type PromptTemplate = {
  readonly id: string;
  readonly applicationType: ApplicationType;
  readonly systemPrompt: string;
  readonly userPromptTemplate: (context: PromptContext) => string;
  readonly maxTokens: number;
  readonly description: string;
};

type PromptContext = {
  readonly userInput: string;
  readonly framework: FrameworkType;
  readonly existingFiles?: Array<{
    readonly path: string;
    readonly content: string;
  }>;
  readonly projectMetadata?: {
    readonly name: string;
    readonly description?: string;
  };
};

type ConstructedPrompt = {
  readonly systemPrompt: string;
  readonly userPrompt: string;
  readonly totalTokens: number;
  readonly template: ApplicationType;
};
```

### Prompt Validation Requirements
[Source: architecture.md - Security and Performance]

**Content Validation:**
- Minimum user input length: 10 characters
- Maximum user input length: 2000 characters
- Check for prompt injection attempts
- Sanitize special characters and malicious patterns
- Validate against inappropriate content requests

**Token Limits:**
- System prompt: ~500 tokens
- User prompt: ~1000 tokens
- Context files: ~10000 tokens (with intelligent pruning)
- Total limit: 200k tokens (Claude context window)

### Context-Aware Prompting Strategy
[Source: architecture.md - AI-Specific Development Patterns]

**Context Gathering:**
1. Fetch current project file structure from database
2. Identify relevant files based on user request
3. Extract file contents for context inclusion
4. Prune context to stay within token limits
5. Prioritize recently modified files and dependencies

**Context Pruning:**
- Include full file structure tree (paths only) for all files
- Include full content for files directly mentioned in user prompt
- Include snippets (first 50 lines) for related files
- Summarize remaining files by type and purpose

### Security Considerations
[Source: architecture.md - Security and Performance]

**Prompt Injection Prevention:**
- Sanitize user input to remove command-like patterns
- Validate against known injection techniques
- Use parameterized prompt construction (never string concatenation)
- Implement content security policies for AI requests

**Data Privacy:**
- Never include sensitive data (API keys, passwords) in prompts
- Sanitize file contents before including in context
- Log prompts in debug mode only (never in production)
- Implement PII detection and masking

### Performance Optimization
[Source: architecture.md - AI-Specific Development Patterns]

**Token Management:**
- Pre-calculate token counts for templates
- Implement caching for frequently used prompts
- Use compression for large context files
- Implement lazy loading for context gathering

**Response Time:**
- Parallel processing for context gathering
- Streaming responses for large generations
- Cache template compilations
- Optimize file tree traversal

### Integration with Claude SDK

**Client Usage:**
```typescript
import { getClaudeClient } from '@/lib/integrations/claude/client';
import { buildPrompt } from '@/lib/integrations/claude/prompts';

const client = getClaudeClient();
const prompt = buildPrompt({
  template: ApplicationType.LANDING_PAGE,
  userInput: "Create a SaaS landing page for project management tool",
  framework: FrameworkType.NEXTJS,
  existingFiles: projectFiles
});

const response = await client.messages.create({
  model: env.ANTHROPIC_MODEL,
  max_tokens: prompt.maxTokens,
  system: prompt.systemPrompt,
  messages: [{ role: 'user', content: prompt.userPrompt }]
});
```

### Error Handling
[Source: architecture.md - AI-Specific Development Patterns]

**Validation Errors:**
- `PromptTooShortError`: User input < 10 characters
- `PromptTooLongError`: User input > 2000 characters
- `InvalidContentError`: Content fails security validation
- `TokenLimitExceededError`: Combined prompt exceeds Claude limits
- `InvalidTemplateError`: Template not found or invalid

**Recovery Strategies:**
- Provide clear error messages with correction hints
- Suggest prompt simplification when token limit exceeded
- Offer alternative templates when validation fails
- Log validation failures for prompt improvement
